# HERA-VLM

**多模态 RAG 中的层级证据支撑推理路径**

HERA-VLM 将文档检索与 Qwen2.5-VL-7B 的两阶段训练结合：先用 **LLaMA-Factory 做 SFT**，再用 **EasyR1 做 GRPO 强化学习**。模型输出结构化答案、分步推理和图像证据框，应用支持对 PDF 的单页或多页问答。

[English README](README.md) · [训练与数据说明](docs/training.md) · [奖励函数细节](docs/reward.md)

## 方法流程

1. **监督微调**：使用文档图像、问题、参考答案及带证据框的步骤标注，学习结构化输出。
2. **强化学习**：用答案准确性、最终证据定位、证据路径及格式四个方面构建奖励，使用 GRPO 优化。
3. **检索问答**：ColPali 检索候选页，结合文本语义分数重排，再交给适配后的 VLM 生成答案并展示证据框。

训练奖励中的 **ColQwen2** 用于检查步骤与引用图像区域的相似性；应用中的 **ColPali** 用于检索页面，两者用途不同。

## 奖励设计

完整奖励函数入口的默认权重为：

`R = 0.35 × 答案准确性 + 0.30 × 证据定位 + 0.25 × 证据路径 + 0.10 × 输出格式`

- 答案准确性：精确匹配、token F1、句向量相似度。
- 证据定位：IoU、参考区域覆盖、合并参考框 IoU、软阈值及坐标有效性。
- 证据路径：步骤文本与图像裁剪的 ColQwen2 相似性、证据框重叠约束、标注层级顺序；由答案准确性阈值控制。
- 输出格式：`<think>`、`<answer>`、`<evidence>` 三段结构、编号步骤及可解析的证据框。

完整实现的顺序分数由单调转换比例与覆盖率组成，并不是简单的二值顺序判断。完整公式和无答案样本规则见[奖励说明](docs/reward.md)。
